# 模型、分组与自动选择

在 workbar 中，**模型**决定 AI 能做什么，**分组**决定这次请求可以使用哪些服务及如何计费，**模型限制**则进一步缩小某一把 API 密钥可以调用的模型范围。

理解这三者后，你就能判断模型为什么会出现、消失或暂时不可用，也能在“自动”和固定分组之间做出选择。

## 先理解三者的关系

| 名称 | 它决定什么 | 在哪里查看或设置 |
| --- | --- | --- |
| 模型 | 实际完成聊天、写作、编程等任务的 AI | “模型广场”和 AI 工具的模型列表 |
| 分组 | 可用模型、服务范围和计费规则 | 创建或编辑 API 密钥时选择 |
| 模型限制 | 这把密钥额外允许哪些模型 | API 密钥的“高级设置” |

一把密钥最终能否调用某个模型，需要同时满足：

1. 模型存在于这把密钥可用的分组中；
2. 如果设置了模型限制，目标模型也在允许名单中；
3. 模型及对应服务当前可用；
4. 密钥已启用、未过期且额度正常；
5. 账号余额和其他访问限制正常。

因此，“模型限制留空”只表示不再缩小范围，不代表平台上的所有模型都能使用。

## 在模型广场查看当前信息

打开顶部导航中的[模型广场](https://workbar.ai/pricing)，搜索准备使用的模型。重点查看：

- **模型名称**：填写到 AI 工具中的准确名称；
- **计费类型**：按 Token 或按次计费；
- **输入、输出及缓存价格**：仅在相应计费方式和能力生效时使用；
- **可用分组**：模型目前在哪些分组中可用；
- **接口类型**：模型支持的兼容接口或能力入口。

模型、价格和分组会随服务配置变化。实际使用前以模型广场当前显示为准，不要把旧截图或旧价格当作长期固定值。

## 自动分组如何工作

创建 API 密钥时不选择具体分组，密钥会保存为“自动”。自动不是一个单独的定价分组，而是一套由系统配置的选择顺序。

一次请求大致会这样处理：

1. workbar 读取当前的自动分组顺序；
2. 排除你的账号不能使用的分组；
3. 按顺序寻找支持目标模型的可用服务；
4. 按实际选中的分组规则计费。

请特别注意：

- 自动分组按照系统配置的顺序选择，**不等于自动选择最低价**；
- 如果密钥开启了“跨分组重试”，当前服务失败后，系统可以继续尝试顺序中的后续分组；
- 重试只能增加后续尝试机会，不能保证请求一定成功；
- 自动分组的顺序和你可用的分组都可能变化，以页面当前结果为准。

## 固定分组与自动分组怎么选

| 你的需求 | 建议 |
| --- | --- |
| 第一次使用，希望少做配置 | 使用自动分组，模型限制先留空 |
| 希望服务异常时有更多后续尝试机会 | 使用自动分组，并在页面提供该选项时开启跨分组重试 |
| 希望明确使用某一组服务和计费规则 | 选择固定分组 |
| 只允许某个项目使用少数模型 | 选择合适分组，再设置模型限制 |
| 比较不同分组的效果或费用 | 为测试单独创建密钥，并分别选择固定分组 |

选择固定分组后，这把密钥只使用该分组中的模型和计费规则。目标模型不在该分组中，或该分组暂时没有可用服务时，请求不会获得自动分组的完整选择范围。

## 模型限制如何随分组变化

创建或编辑密钥时，“模型限制”的候选项会跟随上方分组变化：

- **选择固定分组**：显示该分组当前可用的模型；
- **不选择具体分组**：显示自动分组顺序中所有当前可用分组的模型集合，重复名称会合并；
- **模型限制留空**：不再对这把密钥增加额外限制；
- **选择一个或多个模型**：这把密钥只允许调用所选模型。

修改分组后，原先选择的模型可能不再属于新分组。保存前重新检查模型限制，避免 AI 工具突然看不到需要的模型。

## 看不到模型时按顺序检查

1. 在模型广场搜索目标模型，确认它当前存在且可用；
2. 检查密钥使用的是自动分组还是固定分组；
3. 固定分组下，确认目标模型属于该分组；
4. 检查“高级设置 → 模型限制”是否排除了目标模型；
5. 确认密钥已启用、未过期且额度正常；
6. 确认账号余额正常；
7. 在 AI 工具中刷新或重新同步模型列表。

workbar Code 用户可按[《使用 workbar Code》](../tools/workbar-code.md)重新检测模型；其他客户端可按[《连接其他兼容工具》](../tools/compatible-tools.md)核对地址和模型字段。

如果仍然失败，打开“使用日志”查找对应请求。完全没有日志时，问题更可能发生在工具配置、网络连接或请求到达 workbar 之前。

## 核对一次请求实际用了什么

1. 打开控制台侧边栏中的“使用日志”；
2. 按时间、模型或 API 密钥名称缩小范围；
3. 打开对应记录，查看模型、用量、费用和请求详情；
4. 使用自动分组时，在详情中确认实际选中的分组。

模型广场说明“当前怎样计费”，使用日志记录“这一次实际发生了什么”。费用核对方法请参阅[余额、价格与使用记录](../billing/balance-pricing-and-usage.md)。
