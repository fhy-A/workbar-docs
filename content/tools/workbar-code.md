# 使用 workbar Code

workbar Code 是一个运行在 Windows 电脑上的 AI 编程工具。它以浏览器作为操作界面，可以围绕你选择的本地文件夹查看文件、搜索内容、分析项目，并在你选择的权限范围内修改文件或运行命令。

这篇文档会帮你完成以下事情：

- 下载并启动 workbar Code；
- 连接 workbar 账号，同步 API 密钥和可用模型；
- 选择项目、模型和权限模式；
- 用更安全的方式完成日常任务；
- 理解哪些数据留在本地，哪些内容会发送给模型。

> 如果你还没有 workbar 账号或 API 密钥，请先按照[《快速开始》](../getting-started/quick-start.md)完成首次配置。

## 开始前准备

你需要：

- 一台可以联网的 Windows 电脑；
- 一个已经登录的 workbar 账号；
- 账号中至少有一把已启用的 API 密钥；
- 一个准备让 Code 查看或处理的本地文件夹。

如果你准备让 Code 修改重要项目，建议先使用 Git 保存当前版本，或者备份整个文件夹。

## 第一步：下载并启动 Code

1. 打开 [workbar Code 页面](https://workbar.ai/code)。
2. 下载 Windows 版程序。

![workbar Code 下载页面：Windows 版下载入口](../../assets/images/getting-started/code-download-entry.jpg)

_在 workbar Code 页面选择 Windows 版下载。页面上的版本、文件大小等信息以实际显示为准。_

3. 下载完成后，双击运行 Code。
4. 程序会常驻在 Windows 系统托盘，并在浏览器中打开：

```text
http://127.0.0.1:3010/
```

这是你电脑上的 Code 操作页面，不是公网网站，也不是需要手动填写的模型地址。只要 Code 程序仍在运行，你就可以稍后重新打开这个地址。

> **完成标志**<br>
> 浏览器成功打开 Code 页面。首次使用时，页面会显示“连接到 workbar”。

## 第二步：连接 workbar 账号

1. 在“连接到 workbar”页面点击“连接 workbar”。
2. 浏览器会打开 workbar 的登录或授权页面。
3. 如果尚未登录，请先完成登录。
4. 在授权页点击 `Connect`（连接）。
5. 授权成功后，页面会自动返回 Code，请等待账号信息、API 密钥和模型列表同步。

授权过程在 workbar 页面完成，Code 不会获取或保存你的 workbar 登录密码。模型服务地址已经固定为 `https://workbar.ai`，不需要另外填写 Base URL。

普通刷新不会要求你反复登录。只有授权失效、主动退出账号，或者更换了本地 Code 实例时，才可能需要重新连接。

> **完成标志**<br>
> 连接提示消失并进入 Code 主界面。如需确认账号状态，可打开“设置 → workbar 账号”查看“已连接 workbar”。

## 第三步：确认密钥和模型已同步

登录或启动后，Code 会在后台同步当前 workbar 账号中的可用 API 密钥，并刷新可用模型。这是默认流程，正常情况下不需要手动复制密钥。

如果模型选择器中没有内容，可以按下面的顺序检查：

1. 打开“设置 → 模型”。
2. 先确认 Key 列表中至少有一把已启用密钥。
3. 如果所需密钥没有出现，点击“从 workbar 获取”；在弹窗中复制所需密钥，再粘贴到 Key 列表。
4. 点击“可用模型”旁的“重新检测可用模型”图标。

还是没有模型时，请回到 workbar 控制台检查：

- API 密钥是否已启用；
- 密钥的分组是否有可用模型；
- 密钥的“模型限制”是否排除了你要使用的模型；
- 账号余额是否足够。

Code 会对密钥做脱敏显示。请不要把完整密钥粘贴到会话、截图、问题反馈或公开文档中。

> **主动移除密钥时请注意**<br>
> 如果你在 Code 中主动移除了一把从 workbar 同步的密钥，后续的静默同步不会自动把它加回。需要再次使用时，请在“从 workbar 获取”弹窗中复制该密钥，再粘贴到 Key 列表。

## 第四步：选择项目目录

1. 在 Code 左侧栏的“文件”区域，点击当前文件夹名称。
2. 选择“选择文件夹…”，再选择一个本地文件夹作为当前项目。
3. 确认左侧栏显示的目录和文件树符合预期。

项目目录是 Code 理解任务和操作文件的主要工作范围。选择目录不代表 Code 会立即上传整个文件夹；它会根据具体任务查看目录、搜索文件，并读取完成任务所需的内容。

第一次使用时，可以先选择一个空文件夹、测试项目或已经备份的项目。

## 第五步：选择模型

1. 点击输入框下方的“选择模型”。
2. 从列表中选择一个当前可用的模型。
3. 推理强度不确定时，保持“自动”即可。

Code 中显示的列表是当前账号、API 密钥、分组和模型限制共同决定的实际可用结果。如果 [workbar 模型广场](https://workbar.ai/pricing)中有某个模型，但 Code 中没有出现，应先检查密钥、分组和模型限制，然后重新检测可用模型。

## 第六步：选择权限模式

权限模式决定 Code 能在当前任务中做到什么。发送任务前，请根据目的选择合适的模式。

| 权限模式 | Code 可以做什么 | 适合什么情况 |
| --- | --- | --- |
| 只读分析 | 查看、搜索和分析项目，不修改内容。 | 第一次使用、了解项目、排查原因、代码评审。 |
| 计划 | 分析项目并给出实施方案，不执行写入操作。 | 希望先确认方案、估算影响范围。 |
| 接受编辑 | 可以读取和修改文件；实际编辑或有副作用的操作需要你确认。 | 大多数日常开发任务。 |
| 自动 | 在当前策略允许的范围内自动执行操作，不逐项请求确认。 | 已熟悉项目、任务边界清楚，且项目已有 Git 或备份保护。 |

不确定时，从“只读分析”开始。需要实际修改时，再切换到“接受编辑”。“自动”适合已经理解 Code 行为、能够审核结果的用户，不建议在未备份的重要目录中直接使用。

## 第七步：发送第一个任务

可以先使用“只读分析”模式，发送：

```text
请阅读当前项目，说明它的用途、主要文件和运行方式。不要修改任何文件。
```

Code 会在会话中显示进度、工具操作和最终回答。任务完成后，可以对照项目内容检查回答是否合理。

当你准备让 Code 修改内容时，建议把任务写成下面这种结构：

```text
目标：修复首页上的登录按钮链接。
范围：只修改首页相关文件，不改后端接口。
验收：点击登录按钮后打开登录页，其他导航不受影响。
完成后请检查改动并说明验证结果。
```

清楚的“目标、范围、验收”可以减少误解，也方便你检查 Code 是否真正完成了任务。

## 日常使用建议

### 先选择对的项目，再发送任务

发送前确认项目名称和目录正确，尤其是当你同时维护多个项目时。

### 用权限模式表达你的真实意图

- 只想知道原因：用“只读分析”。
- 想先看方案：用“计划”。
- 希望完成修改，并在关键操作前确认：用“接受编辑”。
- 对项目和任务已经很熟悉：再考虑“自动”。

### 在确认修改前检查对象和差异

“接受编辑”模式中出现文件修改或命令确认时，先看清目标文件、操作内容和 Diff。不确定时可以取消，并让 Code 重新说明方案。

### 要求 Code 验证，不只是“说已完成”

如果项目已经有测试、构建或检查命令，可以在任务中要求 Code 运行。最后检查回答中是否列出了真正执行的验证和结果。

### 定期检查更新

打开“设置 → 更新”，可以检查是否有新版本。安装更新前，建议等当前任务完成。

## 任务运行、刷新和停止

Code 的任务由本地程序承载。刷新页面、切换会话或新建会话，通常不会取消已经在运行的任务。重新打开时，Code 会根据已保存的任务状态重新连接。

如果你确定不再需要当前任务，请使用界面中的停止操作，而不是只关闭浏览器标签页。执行命令或外部请求时，停止信号需要短暂时间收敛；完成后请确认页面显示已停止或已取消。

## 数据与隐私边界

### 留在你电脑上的内容

Windows 正式版默认将 Code 数据保存在：

```text
%USERPROFILE%\.code\
```

其中包括会话、任务状态、附件、文件备份、项目记忆和 Skills 等本地数据。你选择的项目文件仍然保存在原来的文件夹中。

Code 的 Web 服务只监听本机地址 `127.0.0.1`，默认不向局域网公开这个界面。

### 可能发送给模型的内容

为了完成任务，Code 会通过 workbar 将下面的必要内容发送给你选择的模型服务：

- 你输入的任务和后续消息；
- 任务中被读取并需要用于分析的项目内容；
- 必要的工具结果、错误信息和会话上下文。

不要让 Code 处理你无权发送给外部模型服务的机密文件、密码、私钥或个人敏感信息。

### 账号与密钥边界

- workbar 登录状态用于账号授权、API 密钥同步和模型列表。
- Code 使用 API 密钥发起模型请求，不会把完整密钥写入会话正文或持久化的任务运行记录。
- 退出 Code 中的 workbar 账号时，本地保存的平台授权、API 密钥、模型列表和当前模型选择会被清除。
- 退出账号不会删除本地会话、项目目录、记忆、附件、备份或项目文件。

这意味着，账号退出和本地数据删除是两件不同的事情。在公用电脑或要移交的电脑上，请同时检查 Code 的本地数据和原项目目录。

## 常见问题

| 现象或提示 | 处理方法 |
| --- | --- |
| 双击后没有打开页面 | 先检查 Windows 系统托盘中是否有 Code，然后手动打开 `http://127.0.0.1:3010/`。 |
| 打开 3010 时显示无法连接 | Code 本地程序没有运行或正在启动；重新运行程序后再试。 |
| 一直停留在“连接到 workbar” | 确认 workbar 网页已登录，重新点击连接并完成授权。 |
| 提示授权已过期 | 点击重新验证或重新连接 workbar。 |
| 已连接，但没有 API 密钥 | 确认 workbar 账号中至少有一把已启用密钥。先刷新或重新打开 Code；仍未出现时，在“设置 → 模型 → 从 workbar 获取”中复制所需密钥，并粘贴到 Key 列表。 |
| 没有可选模型 | 刷新可用模型，并检查密钥分组、模型限制和账号余额。 |
| 提示“模型未授权” | 在 workbar 调整该密钥的模型限制，或者改用有该模型权限的密钥；然后刷新模型列表。 |
| 提示 API 密钥无效或 `401` | 检查密钥是否被禁用、删除或更换，必要时新建密钥后重新同步。 |
| 提示余额不足 | 打开 workbar “钱包”检查余额，根据需要充值。 |
| 提示请求过于频繁或 `429` | 暂停一会后重试，避免短时间内反复发送大量任务。 |
| 提示模型服务暂时不可用或出现 `5xx` | 稍后重试，或者切换到另一个当前可用模型。 |
| 提示权限不允许当前操作 | 检查当前是否为“只读分析”或“计划”；确实需要修改时，再切换到“接受编辑”。 |
| 项目目录不存在 | 重新选择一个实际存在的文件夹。如果目录在移动磁盘中，先确认磁盘已连接。 |
| 首个回答长时间没有出现 | 等待页面的慢响应提示；超时后可重试、换模型，或检查 workbar 使用日志。 |

需要反馈问题时，可以记录 Code 版本号、模型名称、错误文字、发生时间和 workbar 使用日志中的对应记录。请务必隐藏完整 API 密钥、登录信息、本地路径和私密文件内容。

## 常见疑问

### 可以关闭浏览器页面吗？

可以。关闭浏览器标签页不等于退出 Code。只要系统托盘中的 Code 程序仍在运行，就可以通过 `http://127.0.0.1:3010/` 重新打开。已在运行的任务由本地服务保持；需要立即停止时，请在界面中操作。

### 需要自己填写 Base URL 吗？

不需要。workbar Code 的模型服务地址固定为 `https://workbar.ai`。

### 可以同时使用多把 API 密钥吗？

可以。Code 会维护本地密钥列表，并根据每把密钥实际可访问的模型刷新模型目录。为不同用途创建独立密钥，更容易查看使用记录和管理权限。

### 退出账号后，会话和项目会被删除吗？

不会。退出会清除平台授权、本地 API 密钥和模型信息，但不删除本地会话、项目目录、记忆、附件、备份或原项目文件。
