# 账号与安全

账号安全设置集中在“个人资料”页面。你可以在这里修改基本资料、管理登录方式、启用双重身份验证或 Passkey，并在不再使用账号时申请注销。

页面上实际出现的登录和绑定方式由当前系统配置决定，以你看到的选项为准。

## 登录、找回密码与修改密码

### 无法登录时

1. 确认输入的是当前账号的用户名或邮箱；
2. 检查密码前后是否多了空格；
3. 如果开启了双重身份验证，等待验证码更新后再输入；
4. 仍然无法登录时，在登录页使用“忘记密码”。

密码重置邮件只会发送到账号当前绑定的邮箱。收不到邮件时，检查垃圾邮件、邮箱拦截规则和填写的地址，不要连续反复发送。

### 修改密码

1. 登录后打开“个人资料”；
2. 进入“安全”区域；
3. 按页面要求填写当前密码和新密码；
4. 保存后，在其他设备上使用新密码重新登录。

新密码应当只用于 workbar，不要与邮箱、支付账号或其他网站共用。

## 管理邮箱和第三方登录

邮箱用于验证身份、找回密码和接收重要通知。更换邮箱前，请确认新邮箱可以正常收信，并按页面提示完成验证。

如果页面提供第三方登录绑定，可以把它作为额外登录方式，但不要把它当作唯一恢复手段。第三方服务可能暂时不可用或被解绑，建议同时保留可访问的邮箱和独立密码。

## 启用双重身份验证

双重身份验证会在密码之外，再要求一个随时间变化的验证码。

### 开启步骤

1. 打开“个人资料 → 安全”；
2. 找到“双重身份验证”并开始设置；
3. 使用可信的验证器应用扫描二维码；
4. 输入验证器生成的验证码完成确认；
5. 下载或抄写备用码，并保存到安全、离线的位置。

> **重要**<br>
> 二维码、设置密钥、实时验证码和备用码都可以用于通过身份验证，不能截图公开或发送给他人。

### 验证码一直无效

1. 把手机和电脑时间设置为自动同步；
2. 确认使用的是 workbar 对应的验证器条目；
3. 等待新一组验证码出现后再输入；
4. 验证器不可用时，使用一枚尚未使用的备用码。

更换手机前，先确认新设备已经能生成有效验证码，或保留可用备用码，再移除旧设备上的条目。

## 使用 Passkey

Passkey 可以使用设备解锁、指纹、安全密钥或密码管理器完成登录，减少输入密码和遭遇钓鱼的风险。

注册 Passkey 时：

1. 在“个人资料 → 安全”中选择添加 Passkey；
2. 按浏览器或系统提示完成设备验证；
3. 为 Passkey 使用容易识别的名称；
4. 保留至少一种其他可用的登录或恢复方式。

Passkey 是否能在多台设备间同步，取决于设备、浏览器和密码管理器。它没有出现在另一台设备上，不一定表示 workbar 账号异常。

## 分清四类凭据

| 凭据 | 用途 | 不应填到哪里 |
| --- | --- | --- |
| 登录密码 | 登录 workbar 网页 | AI 工具的 API Key 输入框 |
| 双重身份验证码或备用码 | 登录时确认身份 | 聊天窗口、配置文件或问题反馈 |
| API 密钥 | 让 AI 工具调用模型 | 登录密码框或公开截图 |
| 系统管理访问令牌 | 调用账号管理类 API | 普通 AI 工具或模型请求配置 |

### 系统管理访问令牌警示

“个人资料 → 安全 → 访问令牌”中的令牌用于系统管理接口，权限范围与普通 API 密钥不同。普通用户连接 AI 工具时，只应使用“API 密钥”页面创建的密钥。

- 不要把系统管理访问令牌填入 OpenAI、Claude、Gemini 或其他模型工具；
- 不要在截图、聊天或工单中提供完整令牌；
- 如果令牌疑似泄露，立即在安全设置中重新生成；
- 重新生成后，使用旧令牌的管理脚本或自动化会失效，需要更新配置。

## 凭据疑似泄露时

### API 密钥泄露

1. 立即在“API 密钥”页面停用或删除泄露的密钥；
2. 创建新密钥，并只授予需要的分组、模型和额度；
3. 在可信工具中替换旧密钥；
4. 检查使用日志中是否有未知请求。

只修改登录密码不会让已泄露的 API 密钥失效。完整处理方法请参阅[管理 API 密钥](../keys/manage-api-keys.md)。

### 登录密码或系统管理访问令牌泄露

1. 立即修改登录密码或重新生成访问令牌；
2. 检查邮箱、第三方登录和安全设置是否被改动；
3. 检查 API 密钥列表和使用日志；
4. 把发生时间、异常操作和脱敏后的信息提供给管理员。

任何排查过程都不需要你提交完整密码、API 密钥、访问令牌、验证码或备用码。

## 注销账号前必须知道

“个人资料 → 安全 → 删除账号”是不可逆操作。页面会要求输入当前用户名确认。

当前的自行注销采用软删除方式。注销后：

- 账号会失去登录和继续使用资格；
- 账号下的 API 密钥会被清理，已连接的工具无法继续调用；
- 已绑定的第三方登录关系会被清理；
- 原用户名和邮箱不会自动释放，不能依赖重新注册恢复账号；
- 其他数据如何保留或处理，以当前隐私政策和管理员说明为准。

如果只是暂时不用，请退出登录并停用不需要的 API 密钥。需要继续使用原邮箱或处理账号数据时，请在注销前联系管理员确认。

> **完成标志**<br>
> 只有在确认不再使用该账号、已保存必要记录并理解用户名和邮箱不会自动释放后，才执行注销。
