# 管理 API 密钥

API 密钥是 AI 工具使用你的 workbar 账号调用模型时所需的凭据，通常以 `sk-` 开头。建议为每个工具或设备单独创建一把密钥，这样更容易查看用量，也能在需要时只停用对应工具。

如果你还没有完成第一次连接，请先阅读[《快速开始》](../getting-started/quick-start.md)。本文主要介绍密钥的创建、复制、限制、更换和安全管理。

## 为什么建议每个工具使用独立密钥

一把密钥可以填入多个工具，但不建议长期共用。独立密钥可以帮助你：

- 从使用日志中分辨请求来自哪个工具或设备；
- 为临时用途单独设置到期时间、额度或模型范围；
- 在设备丢失、工具停用或出现异常消耗时，只撤销对应密钥。

名称可以直接使用工具或设备名，例如“家用电脑”“Claude Code”或“测试脚本”。

## 创建 API 密钥

1. 登录 workbar，打开顶部导航中的“控制台”。
2. 在控制台侧边栏中进入“API 密钥”。
3. 点击右上角的“创建 API 密钥”。
4. 填写一个容易识别的名称。
5. 按需要检查分组、到期时间、额度和“高级设置”。
6. 点击“保存更改”。

第一次创建时，大多数用户可以按下面的方式设置：

| 设置项 | 建议怎么选 | 什么时候需要修改 |
| --- | --- | --- |
| 名称 | 填写工具或设备名 | 名称只用于识别，不影响模型能力。 |
| 分组 | 不选择具体分组 | 保存后会显示为“自动”；需要固定模型范围或计费规则时再指定分组。 |
| 到期时间 | 自己的常用设备可选“永不过期” | 临时设备或短期脚本应设置明确的到期时间。 |
| 无限配额 | 保持开启 | 需要限制单把密钥的最高用量时关闭，并设置额度。 |
| 数量 | 保持 `1` | 只有明确需要多把相同设置的密钥时才增加；除第一把外，其余名称会增加随机后缀。 |
| 模型限制 | 保持为空 | 只允许少数模型时再选择。 |
| IP 白名单 | 保持为空 | 仅在服务器公网 IP 固定且你清楚限制影响时设置。 |

“无限配额”只表示不为这把密钥单独设置用量上限，不代表免费或拥有无限余额。调用模型仍会消耗 workbar 账户余额，额度单位以页面当前显示为准。

### 分组和模型限制如何配合

- **不选择具体分组**：新密钥会保存为“自动”，workbar 按系统配置的自动分组顺序寻找当前可用服务。
- **选择固定分组**：这把密钥只能使用该分组中的模型和计费规则，不会自动改用其他分组。
- **模型限制留空**：不在分组范围之外继续缩小可用模型。
- **选择模型限制**：这把密钥只能使用被选中的模型。

模型限制的候选项会随分组动态变化。未选择具体分组时，候选项来自自动分组顺序中所有当前可用分组的模型集合。留空不代表平台上的所有模型都一定可用，模型仍须存在于固定分组或自动分组的可用范围内。

自动分组按后台配置的顺序工作，不等同于自动选择最低价格。详细规则见[《模型、分组与自动选择》](../models/models-and-auto-routing.md)。

### IP 白名单是高级设置

IP 白名单适合公网 IP 固定的服务器。家庭网络和移动设备的公网 IP 可能变化，不清楚时请保持为空，否则可能导致密钥无法使用。它也不能代替妥善保管密钥。

> **完成标志**<br>
> 新密钥出现在列表中，并且状态为“已启用”。

## 复制并填入 AI 工具

API 密钥列表默认只显示脱敏后的内容。找到对应名称后，点击密钥旁的复制按钮；完整密钥会进入剪贴板。只把它粘贴到可信工具的 API Key 字段中，不要放入聊天、截图、问题反馈或临时文档。

使用 workbar Code 时，首次授权通常会自动同步账号中已启用的密钥，不需要提前复制。只有自动同步没有带入所需密钥，或你曾在 Code 中主动移除密钥时，才需要按[《使用 workbar Code》](../tools/workbar-code.md)中的手动补充流程操作。

下面三种信息不要混淆：

| 信息 | 用途 |
| --- | --- |
| API 密钥 | 让 AI 工具调用模型。 |
| Base URL | 告诉工具把请求发送到哪个服务地址。 |
| 登录密码 | 登录 workbar 网站，不能代替 API 密钥。 |

不同工具要求的 Base URL 格式可能不同。使用 Claude Code 时请阅读[《在 Claude Code 中使用 workbar》](../tools/claude-code.md)，其他工具请阅读[《连接其他兼容工具》](../tools/compatible-tools.md)，不要仅凭经验增删路径。

## 编辑、停用和删除

| 操作 | 作用 | 什么时候使用 |
| --- | --- | --- |
| 编辑 | 调整名称、分组、到期时间、额度和限制 | 工具用途或权限发生变化时。 |
| 停用 | 立即停止这把密钥的调用；密钥未过期且仍有可用额度时可以重新启用 | 暂时不用、排查异常或怀疑泄露时。 |
| 删除 | 永久删除，不能撤销 | 已确认所有相关工具都改用新密钥后。 |

如果密钥已经过期或额度耗尽，请先编辑到期时间或额度，再重新启用。修改分组或模型限制后，已经连接的工具可能立刻失去某些模型的访问权限。只是暂停使用时请选择“停用”，不要直接删除。

## 更换密钥和处理泄露

日常更换可以按下面的顺序完成：

1. 创建一把用途相同的新密钥。
2. 在对应 AI 工具中替换旧密钥。
3. 发送一次简单请求，确认新密钥可用。
4. 停用旧密钥。
5. 查看使用日志，确认没有工具继续使用旧密钥。
6. 确认无误后删除旧密钥。

不同工具的替换方式请进入对应的工具专题查看。

如果怀疑密钥已经泄露，不要等待旧密钥的测试结果：先立即停用旧密钥，再创建新密钥并替换工具配置。

## 安全底线

- 每个工具或设备使用独立密钥；
- 完整密钥只粘贴到可信工具的配置中；
- 不把完整密钥写入公开仓库、前端代码、截图或聊天记录；
- 临时用途设置到期时间或单独额度；
- 设备丢失、工具停用或发现未知消耗时，立即停用对应密钥。

## 常见问题

### 工具提示 `401` 或密钥无效怎么办？

重新使用列表中的复制按钮获取完整密钥，检查密钥是否已启用、是否到期，以及工具中的密钥前后是否多出空格。如果仍然失败，继续按[《常见问题排查》](../troubleshooting/common-problems.md)检查；如果密钥来源不明或可能泄露，请直接停用并更换。

### 模型广场中有模型，为什么工具里没有？

检查密钥选择的分组和模型限制，再刷新工具的模型列表。模型还可能因服务状态、账号余额或工具缓存而暂时不可用，最终范围以工具实际刷新结果为准。

### 可以把同一把密钥给多个人使用吗？

不建议。共享后很难判断异常请求来自哪里，也无法只撤销某一个人的权限。应为不同人员、工具或设备分别创建密钥。
